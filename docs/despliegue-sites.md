# Publicar Cardioscopio en Sites desde la nube

Cardioscopio tiene un proyecto de Sites registrado con ID `appgprj_6af487f5ebdc81918d61331b0ba4e9be` y slug `cardioscopio-ecg`. El repositorio de publicación era inaccesible desde el ejecutor local. El proyecto sigue pendiente de una publicación verificada.

En una sesión de Codex en la nube, adjunta `Cardioscopio-Sites.zip` y descomprímelo en el directorio de trabajo. Conserva el manifiesto `.openai/hosting.json` y reutiliza el proyecto indicado. La carpeta `dist/` está preparada como sitio estático. Con la skill de Sites, sincroniza el código con el repositorio de publicación, guarda la versión y despliega. Configura el acceso público solicitado para que funcione con el enlace sin iniciar sesión, y abre la URL de producción en una sesión anónima para comprobarlo.

El paquete publica el flujo de práctica con material simulado o público autorizado. El uso con registros de pacientes requiere una compilación privada y la aprobación del piloto. [Requisitos de investigación](investigacion-colombia.md)
