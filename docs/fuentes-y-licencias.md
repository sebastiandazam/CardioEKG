## Contenido, marcas e integraciones

- Las explicaciones y el glosario están redactados a partir de referencias clínicas y de fisiología. Las citas enlazan a las publicaciones. Las guías sirven para revisar las explicaciones y los criterios, mientras que los archivos de entrenamiento deben tener términos compatibles con el uso previsto. ESC publica condiciones específicas de licencia para utilizar sus guías en software y modelos. [Guías ESC](https://www.escardio.org/guidelines/clinical-practice-guidelines/all-esc-practice-guidelines/atrial-fibrillation)
- Los nombres de instituciones, proyectos y plataformas identifican la fuente del enlace. Verificar los permisos de marca antes de incluir logos. Las licencias de datos y código tienen su propio alcance. El NHLBI permite enlazar su sitio y exige permiso expreso para su logo. [Política de marca del NHLBI](https://www.nhlbi.nih.gov/about/contact/trademark-branding-and-logo) · [Licencia CC BY 4.0](https://creativecommons.org/licenses/by/4.0/legalcode). GitHub contempla el uso de su logo autorizado para enlaces secundarios a GitHub. [Guía de marca de GitHub](https://brand.github.com/foundations/logo)
- ShaderGradient y Liquid Glass JS son referencias visuales. Si se incorporan archivos de sus repositorios, conservar los avisos de licencia correspondientes. [ShaderGradient](https://github.com/ruucm/shadergradient) · [Licencia de Liquid Glass JS](https://github.com/dashersw/liquid-glass-js/blob/main/LICENSE)
- OpenEvidence se abre por enlace. La pregunta se arma a partir de una categoría del visor, sin campos del ECG ni del paciente. La oferta Enterprise describe acuerdos y acceso institucional para organizaciones que apoyan a profesionales verificados de EE. UU. No se verificó una API pública autorizada para este proyecto. [OpenEvidence](https://www.openevidence.com/) · [OpenEvidence Enterprise](https://portal.openevidence.com/)
